# Coffee Pairing

Read the [shared method](references/method.md) completely before retrieving
context or changing a target.

Coffee Pairing runs Roast and Brew for one named project or task, then applies
the resulting Coffee—the Agent carrying the owner's Taste—to the exact external
target the owner named. It never writes the Bean, Coffee context, or task
interpretation back to Coffee Chat.

Before writing, inventory the exact target and its surrounding task tree.
Write only the named target, leave protected Coffee Chat paths unchanged, and
verify the complete diff after the operation. If the instance, Origin evidence,
scope, or target is Unknown, change nothing.
