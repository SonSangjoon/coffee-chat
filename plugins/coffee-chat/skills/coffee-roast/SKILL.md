# Roast Green Beans into Bean

Read the [shared method](references/method.md) completely before selecting
Green Beans.

Roast selects relevant approved Green Beans for one question or named task.
It identifies recurring value criteria, emphases, tensions, and Unknown
boundaries supported by those records. The result is a contextual Bean that
carries Taste for the current operation.

Roast is read-only and ephemeral. It does not create a global Taste profile,
persist a Bean, modify a Green Bean, or remove provenance. It returns the
selected Green Beans and Origins so downstream Coffee can remain traceable.
