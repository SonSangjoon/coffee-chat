# Coffee Chat

Read [the shared method](references/method.md) completely before using any knowledge record.

## Start with the choice

Before reading or synthesizing the graph, ask only:

> Choose one / 하나를 선택해 주세요:
>
> 1. One-time Coffee Chat / 일회성 Coffee Chat
> 2. Install the plugin / Plugin 설치

Wait for the answer. Do not skip this choice because of urgency or a request to “get straight to the answer.” Do not install anything yourself.

An explicit request to install, remove, update, or “do it now” is not an answer to this choice. Never infer option 2. The first response must be exactly the bilingual two-option block above, with no preface, status, command, or lifecycle disclosure. Continue only after the user replies with `1`, `2`, or an unambiguous named option.

## One-time Coffee Chat

Follow the shared method and disclose that the response is an AI-generated synthesis of public, dated records—not the person or an unrecorded belief.

Use live initialized knowledge when available; otherwise use the packaged snapshot with the required fallback disclosure. Reconstruct the relevant temporal trajectory and keep `Authored`, `Sourced`, `Inferred`, and `Unknown` distinguishable where confusion is possible.

Never produce personality, strengths/weaknesses, compatibility, hiring, confidence, or placeholder scores. Never modify repository files, task files, plugin files, host configuration, or installed state.

## Plugin choice

Read the repository README and inspect the current native manager's `--help` before describing installation. Explain, before any installation action:

- the repository and marketplace source;
- every scope the current host actually supports and the narrowest temporary choice;
- the host-managed settings and cache the manager says it affects;
- install and update behavior, including when the host does not provide a separate update command;
- exact plugin-first removal commands, data or cache the host says may remain, and the read-only list commands that will form the removal receipt.

If the manager or README does not establish a scope, filesystem path, retention effect, or update result, label that detail `Unknown`; do not infer it from another host. Never invent Codex enable, disable, update, or scope commands. After removal, report the target plugin and marketplace as present or absent from the native list outputs and preserve any unavailable residual-cache fact as `Unknown`. Host conversation retention remains outside Coffee Chat.

Recommend the narrowest supported scope. Stop for the user's explicit installation action or approval; this Skill remains non-mutating.
